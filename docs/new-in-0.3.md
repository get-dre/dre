# New in 0.3

DRE 0.3 sends headline numbers to people who don't want a file. Nothing breaks: a project that
works on 0.2 runs unchanged, and older plugins keep working.

- **[Messages](messages.md)**: `format: message` renders a report's results into a short
  headline (a title and a few lines of text) for Slack, Microsoft Teams, Google Chat or an email
  body. It's built in, and also written as a `.md` file that any file destination delivers.
- **Several outputs per report**: `output:` can be a list, each with a `name:` and the
  `queries:` it formats. The queries run once, so the workbook and the headline agree, and a
  message can link to (`outputs.<name>.location`) or attach (`attach:`) the files.
- **`when:`** on any output: skipped, not failed, when its condition over the results is false.
- **Number filters** in every template: `number`, `percent`, `signed`, `currency` and `compact`,
  formatted for a new [`locale:`](templates.md#locale) key (project, folder, report or Set).
- **New destinations**: `teams` and `google_chat` post messages through a webhook (release
  candidates, `1.0.0-rc.1`). `slack` 1.1.0 and `email` 1.1.0 take messages too.
- **`dre run --preview`** prints each message instead of sending it.
- **Records**: `run_results.json` gains `output_results` (one entry per output, with its status
  and, for a message, the full text it sent); the manifest gains `outputs` per Binding. Existing
  fields are unchanged and cover every output.
- **Plugin protocol**: destinations can advertise `message` and `message_only`, `deliver` can
  carry a message, and `describe` a message length limit (`dre-protocol` 0.3.0). See
  [the protocol](protocol.md#messages).

To use messages in Slack or email, update those packages: `dre plugin update slack` and
`dre plugin update email`. Add `teams` or `google_chat` under `plugins:` in `dependencies.yml`
to use them. The schemas for editor checks are at `/schemas/v0.3/`.
