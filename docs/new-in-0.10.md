# New in 0.10

DRE 0.10.0 adds generic JDBC source support and updates MiniJinja to 3.0.5. Its release also
publishes `dre-protocol` 0.11.0 with the JDBC metadata capability. Plugin versions remain
independent of the core version. Release the required plugin packages before the core.

## JDBC sources

The optional JDBC plugin uses Java 17 or newer and vendor JDBC drivers installed and maintained
by the operator. DRE does not bundle Java, download it, or supply database drivers. Configure the
Java executable with `JAVA_HOME` or put it on `PATH`; install JDBC with the normal
`dre plugin install jdbc` workflow. See [JDBC connections](plugin-jdbc.md) for setup and limits.
JDBC 1.0.0 requires DRE 0.10.0 or newer for multi-file installation and catalog metadata.

The plugin accepts a complete JDBC URL or a vendor URL plus driver properties. It discovers
schemas through JDBC metadata. Oracle and SQL Server are the tested database environments;
other compatible drivers are not covered by those tests. Database permissions remain the access
boundary. The plugin does not claim support for every JDBC feature or vendor property.

## Template behavior changes

MiniJinja 3.0.4 and 3.0.5 change some results. Check templates that depend on these behaviors:

- `'{}'.format(0.0)` now returns `0.0`, and `str.format` no longer limits floats to six
  significant digits.
- `"%s"|format(value)` formats floats like Python's `str()`.
- Sorting by several attributes ignores case by default. Set `case_sensitive=true` when a
  case-sensitive order is required.
- `str.find` and `str.rfind` return character offsets rather than byte offsets.
- String `is*` predicates follow Python semantics: `'foo bar'.islower()` is true and
  `''.isdigit()` is false.

These changes may alter rendered values, sort order or template branches. Review outputs that use
float formatting, multi-key sorting, Unicode string offsets or string predicates before deploying
the new core.

## Release compatibility

Install the packages a project uses before upgrading core. The JDBC example also needs the JDBC
1.0.0 and XLSX 1.1.3 plugins. PostgreSQL 1.4.2 and SFTP 1.3.2 include the updated SSH library;
install those releases to receive its fixes. See [Updating DRE](updating.md) for rehearsing a
core update.
